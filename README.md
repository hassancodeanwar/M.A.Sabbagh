# M.A.Sabbagh

**Portfolio Website of Mr. Mohamed Abdelaziz Sabbagh**

A modern portfolio website built with cutting-edge web technologies to showcase professional work and accomplishments.

## Tech Stack

- **Frontend Framework:** React 18 with TypeScript
- **Build Tool:** Vite for fast development and optimized builds
- **Styling:** Tailwind CSS for responsive design
- **Icons:** Lucide React for beautiful, scalable icons
- **Code Quality:** ESLint for code linting and TypeScript for type safety


## Features

- Responsive design optimized for all devices
- Fast performance with Vite
- Type-safe development with TypeScript
- Professional portfolio showcase
- Tailwind CSS for modern styling
